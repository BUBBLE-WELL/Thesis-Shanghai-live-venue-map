Post-Submission: Anchor Probing (August 2026)

Phase 3 anchor probing compares 32 venue-level difference vectors grouped into seven rank-1 Amap-anchor categories. Using jieba segmentation across n=153,290 tokens, the Amap end is relatively stable while the XHS caption end is more dispersed. The right panel shows the existing venue-level Amap–XHS cosine distance (1 − similarity) for the venues with a Phase 2 venue-specific probe vector. LISTEN is omitted because it has a thesis distance but no Phase 2 venue-specific probe vector. These results are lexical and platform-specific; multimodal evidence was not tested, so the figure does not attribute dispersion to images or video.
